# Etsy2Pin Privacy Policy

Operated by **mafpads** · Effective date: October 19, 2026

Etsy2Pin is a small desktop tool used by **mafpads**, an Etsy shop ([etsy.com/shop/mafpads](https://www.etsy.com/shop/mafpads)), to publish its own Etsy product listings as Pins on its own Pinterest account. It is used only by the shop owner and is not offered to other users.

## Information we access

- **Pinterest account data:** with the account owner's authorization, Etsy2Pin reads the owner's list of Pinterest boards and creates Pins (title, description, image, and link to the Etsy listing) on those boards.
- **Etsy listing data:** public information about the shop's own listings (titles, descriptions, tags, prices, images, and links), taken from the shop's public feed or the shop owner's own data export.

Etsy2Pin does not access, collect, or store data about any other Pinterest user, and it does not read other users' Pins or boards.

## How information is used and stored

Information is used only to create and schedule Pins for the shop's own products. The Pinterest access token and the app's settings are stored locally on the shop owner's computer. Etsy2Pin has no server and does not send data to any third party other than Pinterest's own API.

## Sharing

We do not sell, rent, or share any data with third parties.

## Retention and deletion

Data stays on the shop owner's computer until the owner deletes it. Access can be revoked at any time from Pinterest settings (Settings → Security and logins → Apps), which immediately stops Etsy2Pin from accessing the account.

## Changes

If this policy changes, the updated version will be published on this page with a new effective date.
